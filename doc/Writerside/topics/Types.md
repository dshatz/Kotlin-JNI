# Supported Types

The following types are supported for direct mapping:

|  Type   |  ArrayType   |
|:-------:|:------------:|
| Boolean | BooleanArray |
|  Byte   |  ByteArray   |
|  Char   |  CharArray   |
| Double  | DoubleArray  |
|  Float  |  FloatArray  |
|   Int   |   IntArray   |
|  Long   |  LongArray   |
|  Short  |  ShortArray  |
| String  |              |
